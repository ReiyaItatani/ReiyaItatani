## Hi, I'm Reiya Itatani

PhD student at Universitat Politècnica de Catalunya (UPC), Barcelona, supervised by Nuria Pelechano.
Research assistant in Mel Slater's lab at the University of Barcelona.

I work on crowd simulation, virtual and mixed reality, and how people perceive and react to virtual humans.
